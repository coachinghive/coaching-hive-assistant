# Daily brief

One screen. The coach reads it in 60 seconds.

## Steps
1. Read today's calendar (if connected). List each call: time, who, why, and a
   one-line prep note from the second brain or past notes.
2. Read the inbox since the last brief (if connected). Pull only emails that
   need the coach: money, clients, leads, deadlines. Skip newsletters.
3. Read `~/second-brain/kpis.md`. Pick the 3 actions today that most move those numbers.
4. Write the brief in this order:
   - **Today's calls** (time, name, one-line prep)
   - **Needs you** (max 5, each with a drafted reply ready if one is needed)
   - **Top 3 for revenue**
   - **Waiting on others**
5. End with: `Want me to draft any of these?`

## Never
- Send any reply without a yes.
- Pad the brief. If a section is empty, write `None`.
