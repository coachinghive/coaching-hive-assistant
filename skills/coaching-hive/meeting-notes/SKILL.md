# Meeting notes

## Steps
1. Read the transcript or notes.
2. Write:
   - **Summary** (3 lines max)
   - **Decisions**
   - **Action items** (what, who, by when)
   - **Follow-up message** drafted in the coach's voice
3. Ask: `Save these notes to ~/second-brain/notes/? Send the follow-up?`
4. Save only after a yes. File name: `YYYY-MM-DD-name.md`.

## Never
- Add anything the person didn't say.
